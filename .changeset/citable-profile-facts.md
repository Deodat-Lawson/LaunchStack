Values typed into the company profile are citable evidence. The profile view numbers each
typed fact like a document excerpt (titled with the fact's label, `origin: "profile"`, no
document), and grant drafts can cite these values after the retrieved excerpts. They rest on
no document, so they never make a draft's source provenance unknown or widen an export's
audience. `builtFrom.snippets` still counts document excerpts only.
