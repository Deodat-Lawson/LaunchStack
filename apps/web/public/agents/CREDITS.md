# Agent avatars — credits

Default pictures for the ten starter agents. Every one is a reproduction of a
two-dimensional work in the public domain, downloaded from Wikimedia Commons
(960px renditions, centre-cropped to 512×512 with `sips`). A workspace can
replace any of them from the agent editor; the editor also offers these ten
as a gallery for custom agents.
